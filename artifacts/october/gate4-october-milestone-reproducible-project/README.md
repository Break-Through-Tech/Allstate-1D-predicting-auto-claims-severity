# Gate 4 — October model development

Bundle ID: `gate4-october-milestone-reproducible-project`

This folder will be the October evidence package. It is empty. Gate 4 stays open until Gates 1 through 3 are approved and a blocking data, split, leakage, metric, or comparison defect is resolved. The lowest displayed MAE does not close the gate.

- `manifests/` — source identity and the frozen split manifest.
- `baselines/` — the verified mean and median validation scores.
- `experiments/` — the experiment register, comparison table, and a way to regenerate validation predictions.
- `registers/` — the anomaly register.
- `review/` — run receipts, the independent rerun, and the team decision.
- `handoff/` — the October report and the November handoff.
